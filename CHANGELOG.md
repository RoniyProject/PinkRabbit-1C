# Новое в версии 2.3

Стабильность и нагрузка на сервер 1С.

* Сокет, AMQP-соединение и каналы используются только потоком ввода-вывода. Поток сеанса 1С передает ему команды через очередь и ждет результат своей операции с таймаутом. Устранены гонки данных AMQP-CPP между потоками, которые приводили к аварийному завершению rphost.
* У каждой операции собственное состояние ожидания: поздний ответ брокера на операцию, завершившуюся по таймауту, больше не завершает следующую операцию.
* Heartbeat: компонента сама отправляет heartbeat каждые pingRate/2 секунд (при pingRate = 0 - интервал сервера) и считает соединение потерянным, если от сервера ничего не приходило 2*pingRate секунд. Брокер больше не закрывает простаивающее соединение с ошибкой missed heartbeats from client.
* Потеря соединения и закрытие канала потребителя передаются в 1С: BasicConsumeMessage вызывает исключение с причиной вместо бесконечного возврата Ложь, IsConnected возвращает Ложь.
* Поток ввода-вывода ждет в WSAPoll без периодических пробуждений (не чаще 1 раза в секунду в простое вместо 60-130), буферы выделяются по потребности (256 КБ вместо 66 МБ на соединение), включены TCP_NODELAY и TCP keepalive (30 с).
* BasicPublish использует publisher confirms вместо транзакции AMQP на каждое сообщение. Новый необязательный параметр waitConfirm и новый метод WaitForConfirms для пакетной отправки. Если брокер прислал connection.blocked, BasicPublish сразу завершается ошибкой.
* BasicConsume с noConfirm = Истина подписывается с ручным подтверждением, ack отправляется при выдаче сообщения в 1С: prefetch (selectSize) ограничивает память процесса. BasicAck для таких сообщений допустим.
* Теги сообщений монотонно растут в пределах объекта компоненты. BasicAck/BasicReject по тегу закрытого канала или повторное подтверждение вызывают исключение и не отправляют кадр, который закрыл бы канал. Из BasicAck/BasicReject удалена пауза (на Windows 1-16 мс на вызов).
* Новые необязательные параметры: BasicAck(тег, multiple), BasicReject(тег, requeue). Новые методы: WaitForConfirms, SetLogLevel, IsConnected.
* Журнал: уровень по умолчанию W вместо D, метод SetLogLevel и переменная окружения PINKRABBITMQ_LOG_LEVEL, сброс на диск только для предупреждений и ошибок, хранение 3 дня. Логгер больше не вызывает исключений на невалидном UTF-8.
* Исключения не выходят за границу Native API и из потока ввода-вывода. Тело или свойства сообщения не в UTF-8 заменяются символом U+FFFD, сообщение больше не теряется.
* Connect: один дедлайн timeout на разрешение имени, TCP-подключение (перебираются все адреса хоста), рукопожатие TLS и вход AMQP; повторный Connect сначала полностью закрывает прежнее соединение. Деструктор ограничен 1 с на штатное закрытие.
* TLS (Windows): рукопожатие с проверкой цепочки и имени хоста выполняется поверх обычного сокета, после чего сокет переводится в неблокирующий режим (иначе Poco ждал 100 мс на каждом чтении). Доверенные корни - хранилище Windows ROOT и файл из переменной PINKRABBITMQ_TLS_CA_FILE, из хранилища CA берутся только промежуточные сертификаты. Уровень безопасности OpenSSL 2, анонимные наборы шифров отключены. Контекст TLS общий для процесса и обновляется раз в час.
* DeclareQueue возвращает имя очереди от сервера (для пустого имени). Заголовки: целые числа кодируются типом l (знаковое 64-битное, совместимо с RabbitMQ и Java), дробные - decimal со знаком, если число представимо точно, иначе double в сетевом порядке байт (AMQP-CPP пишет и читает double в порядке байт хоста). Поддержаны вложенные объекты и массивы, x-stream-offset принимает first/last/next. DeclareExchange поддерживает тип headers.
* BasicConsume проверяет очередь пассивным объявлением на отдельном канале: ошибка в имени очереди не закрывает канал других потребителей. Потребитель, подтвержденный брокером после таймаута BasicConsume, отменяется. BasicCancel возвращает в очередь невыданные сообщения отмененного потребителя.
* Исправлены значения по умолчанию параметров BasicPublish и DeclareExchange, неопределенное поведение при отмене потребителя брокером, гонка при инициализации таблиц имен методов, усечение указателя в GetClassObject.
